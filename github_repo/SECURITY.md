# Security Policy

## Reporting Vulnerabilities in NetWARRIOR Itself

If you find a security vulnerability in NetWARRIOR's own code — not in a target
you're testing, but in the tool itself — please report it responsibly.

Open a GitHub issue tagged `[SECURITY]` or contact the maintainers directly.

Do not open a public issue that contains exploit details for unpatched bugs.

---

## Responsible Disclosure Reminder

If you discover real vulnerabilities in third-party systems while using this tool:

1. **Do not exploit them** beyond what is necessary to confirm the vulnerability
2. **Document your findings** with timestamps and scope
3. **Report to the vendor** through their official security disclosure channel
4. **Allow reasonable time** (typically 90 days) for a fix before public disclosure
5. **Follow your engagement rules** — if you are under a penetration testing
   contract, follow your client's reporting requirements

Common disclosure channels:
- Vendor security pages (look for `security.txt` or a bug bounty program)
- [HackerOne](https://hackerone.com)
- [Bugcrowd](https://bugcrowd.com)
- [CVE Program](https://www.cve.org/ResourcesSupport/ReportRequest)
